## Overview

NetStat Monitor is a tool for monitoring and analyzing network metrics in real time, with a focus on latency, jitter, packet loss and internet access behavior. The project collects data using ping at configurable intervals, stores measurements in CSV files and presents the results in an interactive Streamlit dashboard.

The project documentation is available in English here and in Portuguese in [README.md](README.md).

The main idea is to allow the same data collection session to compare different network layers — LAN, MAN and WAN — through a simple interface without requiring manual IP setup in most cases. For this purpose, the system also includes automatic detection of the gateway and the first external host from the Internet provider.

## Scope changes and project evolution

During development, some initial plans were revised:

- the comparison with the theoretical M/M/1 queue model was removed from the confirmed scope;
- the Streamlit dashboard became a central part of the solution instead of a secondary add-on;
- the collection was structured to work with multiple destinations simultaneously across network layers;
- automatic network detection became a key feature to reduce the need for manual configuration.

These changes preserved the core goal of the project while making the solution more practical, observable and useful for real-world network analysis.

## Implemented features

- periodic latency collection via ping;
- jitter calculation and accumulated packet loss rate;
- simultaneous monitoring of multiple hosts;
- CSV persistence with an architecture prepared for future SQLite support;
- automatic detection of the default gateway on the local network;
- approximation of the first external host through traceroute;
- web interface with Streamlit to start/stop collection and visualize graphs in real time;
- descriptive statistics with mean, median, standard deviation and percentiles;
- outlier detection using IQR;
- correlation between time of day and latency.

## Project structure

- app.py — main Streamlit dashboard;
- coletor/ — collection and network detection modules;
- armazenamento/ — persistence layer for collected data;
- analise/ — statistical analysis and pattern detection;
- visualizacao/ — chart generation and visualizations;
- dados/ — CSV files generated by collections;
- scripts/ — support utilities and synthetic data generation.

## Installation

1. Clone the repository:

   git clone <repository-url>

2. Enter the project folder:

   cd NetStat-Monitor

3. Create and activate a virtual environment:

   python -m venv venv
   .\venv\Scripts\Activate.ps1

4. Install dependencies:

   pip install -r requirements.txt

## Running the project

### Streamlit dashboard

To start the application interface:

   streamlit run app.py

In the interface, you can:

- enter hosts for the LAN, MAN and WAN layers;
- automatically detect the gateway and first external host;
- start and stop data collection;
- visualize latency, jitter and packet loss charts.

### Automatic network detection

To test only the layer detection logic:

   python -m coletor.deteccao_rede

### Direct collection test

The collection module can also be run directly for quick validation:

   python -m coletor.ping_collector

## Typical usage flow

1. the user opens the web app;
2. the system allows host configuration manually or via automatic detection;
3. collection starts across multiple threads;
4. measurements are saved to CSV files;
5. charts and statistical indicators are updated in real time.

## Important notes

- the project is designed as a practical network diagnosis tool, not as a replacement for expert networking analysis tools;
- the MAN layer is treated as an approximation based on traceroute and not as a precise provider identification method;
- gateway and first external host detection is useful as a support feature, but users can still manually correct the values if needed.
